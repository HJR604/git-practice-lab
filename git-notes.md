\# Git notes



\## Four important areas



1\. Working tree: files currently being edited

2\. Staging area: changes selected for the next commit

3\. Local repository: commits stored on this computer

4\. Remote repository: commits stored on GitHub



\## Common commands



\- `git status`: inspect the current state

\- `git add`: stage changes

\- `git commit`: create a local commit

\- `git push`: upload commits

\- `git fetch`: download remote information

\- `git pull`: fetch and integrate remote changes
